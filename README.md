# 平面二连杆机械臂 · 逆运动学求解演示

纯前端（HTML5 Canvas + 原生 JS，零依赖、可离线运行）的 **逆运动学（Inverse Kinematics, IK）** 可视化演示，
对比两种经典求解思路在 **平面 2R 机械臂** 上的效果——对应参考图 `几何解析法.png` / `数值迭代法.png` 中的交互演示。

## 演示内容

| 方法 | 思路 | 页面表现 |
| --- | --- | --- |
| **几何解析法** | 余弦定理闭式求解 | 工作空间圆 + 两个肘部构型（蓝=高手肘 / 绿=低手肘），目标超出范围时提示「目标不可达」 |
| **数值迭代法** | 雅可比阻尼最小二乘（DLS）迭代 | 初始猜测（灰虚线）+ 迭代路径（紫虚线）+ 收敛解（紫实线），支持「播放迭代动画」 |

## 使用方法

1. 直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / Firefox）。
   或本地起一个静态服务：
   ```bash
   python3 -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```
2. 点击画布任意位置 **设置目标点（红 ×）**，或 **按住拖动** 实时移动目标点，逆解随之实时更新。
3. 左侧面板可调节连杆长度 `L₁ / L₂`；切到「数值迭代法」后还可调节初始猜测 `θ₁ / θ₂` 与阻尼 `λ`。
4. 数值法下点击 **▶ 播放迭代动画** 可逐步观察末端如何从初值逼近目标。

## 运动学模型

- 正运动学（Forward Kinematics）：
  `x = L₁·cosθ₁ + L₂·cos(θ₁+θ₂)`，`y = L₁·sinθ₁ + L₂·sin(θ₁+θ₂)`
- 几何解析法：
  `cosθ₂ = (r²−L₁²−L₂²)/(2L₁L₂)`，`θ₁ = atan2(y,x) ∓ β`
- 数值迭代法（阻尼最小二乘）：
  `Δθ = (JᵀJ + λ²I)⁻¹ Jᵀ·e`，每步对 `Δθ` 做步长限制以防奇异处发散。
